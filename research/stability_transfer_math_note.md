# 结构稳定性和结构迁移：数学上为什么必须分开

这份说明专门解决一个容易被审稿人追问的问题：为什么不能用一个“结构鲁棒性分数”同时代表稳定性和迁移。

## 1. 先分清潜在任务和文本

一个任务不是一串文字，而是

\[
z=(G,q,y),
\]

其中 \(G\) 是依赖图，\(q\) 是问题，\(y\) 是符号求解器给出的答案。文本呈现记为 \(r\)，模型真正看到的输入是

\[
x=R(z,r).
\]

这个拆分很重要：改变 \(r\) 不等于改变 \(G\)。如果把两者混在一起，换了写法和换了推理结构就会被错误地算成同一种泛化。

## 2. 稳定性：同一个任务，换一种合法呈现

稳定性实验固定 \(z\)，只从等价呈现集合 \(C_s(z)\) 中抽取 \(r\)。要求所有呈现共享同一张图、问题和答案：

\[
G(T_sx)=G(x),\quad q(T_sx)=q(x),\quad y(T_sx)=y(x).
\]

主指标是

\[
SS(f)=P(f(R(z,r))=y\mid f(R(z,r_0))=y),
\]

其中 \(r_0\) 是 canonical 呈现。它不是普通准确率，而是“在已经展示过能力的前提下，等价改写是否造成翻转”。条件翻转率为

\[
SF(f)=1-SS(f).
\]

如果模型本来就不会原题，把它计入结构不稳定会夸大结构效应；所以条件化是必要的。

## 3. 迁移：换到未见图分布，重新完成推理

迁移实验固定规范呈现规则，但改变依赖图分布。设 \(P_S(G)\) 是已见图族，\(P_U(G)\) 是未见图族，两个支持集在图哈希、图族、算子组合和 base query 上隔离。定义：

\[
R_S(f)=E_{G\sim P_S}[1\{f(x_G^{can})\neq y_G\}],
\]

\[
R_U(f)=E_{G\sim P_U}[1\{f(x_G^{can})\neq y_G\}].
\]

迁移差距是

\[
\Delta_T(f)=R_U(f)-R_S(f).
\]

它测量的是支持集变化带来的风险增量，而不是文本改写带来的翻转。可以再报告归一化保留率

\[
TR(f)=1-\frac{R_U(f)-R_S(f)}{1-R_S(f)},
\]

但论文主结果仍建议使用 \(\Delta_T\)，因为差值更直观，且适合 bootstrap 置信区间。

## 4. 两个量为什么可以分离

### 反例 A：稳定性低，迁移差距小

模型对句子位置或格式高度敏感，但仍然掌握了图上的基本操作。只要未见图使用 canonical 格式，它在新图上仍能答对。此时 \(SS\) 低，但 \(\Delta_T\) 小。

### 反例 B：稳定性高，迁移差距大

模型完全不受模板和前提顺序影响，但只记住训练中出现过的图组合。遇到未见的分支-合取组合时失败。此时 \(SS\) 高，但 \(\Delta_T\) 大。

这两个反例说明：二者相关与否是需要实证检验的研究问题，不是定义上可以预设的结论。

## 5. 实操中的二乘二设计

用图熟悉度 \(g\in\{S,U\}\) 和呈现方式 \(p\in\{can,shift\}\) 形成四格准确率 \(A_{g,p}\)：

\[
\Delta_S=A_{S,can}-A_{S,shift},
\]

\[
\Delta_T=A_{S,can}-A_{U,can},
\]

\[
I_{S\times T}=(A_{S,can}-A_{S,shift})-(A_{U,can}-A_{U,shift}).
\]

四格分别回答：熟悉图的基础能力、熟悉图的呈现稳定性、规范呈现下的新图迁移、以及新图是否会放大呈现脆弱性。四个格子必须使用独立的图池和严格的长度、模板匹配。

## 6. 一句话判断标准

- 只改变呈现，潜在任务不变：这是稳定性。
- 呈现规则固定，依赖图支持集改变：这是迁移。
- 同时改变两者：只能叫交互实验，不能把结果直接当成稳定性或迁移。
