# 从结构稳定性到结构迁移：大模型推理研究框架

## 1. 论文要回答什么

- **论文类型：** 新问题/新分析视角的实证研究。
- **核心问题：** 模型已经会做的一道题，如果只改变题目的组织方式，能不能继续做对？这种稳定性，能不能预测模型处理没见过的依赖结构的能力？哪些结构负担会导致错误？这个规律在哪些情况下失效？
- **StructShift 的角色：** 负责生成和验证数据，是测量工具。
- **LoRA 的角色：** 最后的边界干预，用来观察稳定性改善是否扩展到迁移。

论文不应该写成“做一个 benchmark，再加一个 LoRA”。真正的主线是：**先把稳定性和迁移分开，再找出能预测错误的结构规律，最后检查规律的适用边界。**

## 2. 为什么要区分结构稳定性和结构迁移

### 结构稳定性

结构稳定性问的是：**模型已经展示过的解题能力，能不能在等价呈现下保持住。**

例如，依赖图、问题和答案完全不变，只把前提换成另一种合法顺序。模型原题答对，变体答错，说明它对呈现方式敏感；这不等于它完全不会这道题。

### 结构迁移

结构迁移问的是：**模型能不能把熟悉的局部操作组合到没见过的依赖配置中。**

例如，训练中见过单链、简单合取和简单分支，测试时把这些熟悉算子组合成训练中没有出现过的“分支后再合取”。这里改变的是需要完成的依赖关系，不只是句子顺序。

### 区分的意义

如果不区分，一个 OOD 分数会混合三种情况：

1. 模型在原题上就不会；
2. 模型原题会做，但换一种组织方式就失效；
3. 模型会做局部操作，但不会组合成新结构。

区分以后，可以得到更清楚的诊断：

| 基础能力 | 结构稳定性 | 结构迁移 | 怎么解释 |
|---|---|---|---|
| 低 | 任意 | 任意 | 原题都不会，暂时不能解释结构因素 |
| 高 | 低 | 低 | 呈现脆弱，同时缺少新结构组合能力 |
| 高 | 高 | 低 | 能稳定执行熟悉结构，但不会系统组合新结构 |
| 高 | 低 | 高 | 能处理新结构，但对呈现方式敏感 |
| 高 | 高 | 高 | 最接近稳定、系统的结构化推理 |

所以，稳定性不是迁移的同义词。它们可能相关，也可能分离。研究这种关系本身，就是论文的第一项贡献。

## 3. 四个研究问题

1. **稳定性：** 同一张依赖图、同一个问题、同一个答案，只改变前提顺序或合法呈现方式，模型还能不能保持正确？
2. **迁移：** 稳定性好的模型，面对没见过的依赖图或算子组合时，是否仍然更容易答对？这里必须使用独立数据池。
3. **错误规律：** 相关前提之间的距离、同时需要保留的未完成依赖数量、需要协调的算子数，能不能在控制长度和图规模后预测错误？
4. **边界：** 这个规律能不能搬到第二个任务族？训练带来的是未见结构上的迁移，还是只记住了已见变体？

## 4. 非循环的定义

把样本写成

我们把模型输入写成 \(x=R(z,r)\)，其中 \(z=(G,q,y)\) 是潜在任务，\(r\) 是文本呈现。

### 4.1 稳定性怎么定义：同一任务上的不变性

先把一个推理任务拆成两个层次。潜在任务记为

\[
z=(G,q,y),
\]

其中 \(G\) 是依赖图，\(q\) 是目标问题，\(y\) 是由符号求解器验证的答案；文本呈现 \(r\) 只是把 \(z\) 写成模型能读到的输入 \(x=R(z,r)\)。稳定性变换 \(T_s\) 只能改变呈现方式，因此必须满足：

\[
G(T_sx)=G(x), \qquad q(T_sx)=q(x), \qquad y(T_sx)=y(x).
\]

这一定义的关键不是“变体分数高不高”，而是同一个 \(z\) 内比较两个呈现。令 \(C_s(z)\) 是允许的等价呈现集合，主指标用条件稳定率和条件翻转率：

\[
SS(f)=\Pr[f(T_sx)=y\mid f(x)=y], \qquad
SF(f)=1-SS(f).
\]

它测量的是等价呈现集合内部的方差：潜在任务 \(z\) 不动，只观察模型是否因文本组织改变而翻转。若原题不正确，该样本不能用来声称“换写法导致失效”，所以条件化是必要的。

为了检查条件化本身是否造成偏置，补充报告同一任务内两个随机等价呈现的预测一致率：

\[
INV(f)=\mathbb E_{z}\mathbb E_{r,r'\sim Q_s(\cdot\mid z)}
\mathbf 1\{f(R(z,r))=f(R(z,r'))\}.
\]

\(SS\) 是“已经答对后能否保住答案”，\(INV\) 是“无论答案对错，模型是否对等价呈现保持一致”。二者都高时，稳定性结论最强；若只有 \(INV\) 高而准确率低，只能说明模型稳定地犯同一种错。

同时报告原题准确率、变体准确率、答案一致率和恢复率。

### 4.2 迁移怎么定义：新图支持上的风险变化

迁移时不再固定 \(z\)。我们先定义已见图分布 \(P_S(G)\) 和未见图分布 \(P_U(G)\)，二者可以共享算子词表，但满足图族、图哈希和组合规则的支持集隔离。规范呈现下的风险分别为

\[
R_S(f)=\mathbb E_{G\sim P_S,\,q\sim P(q\mid G)}
\mathbf 1\{f(x_G^{can})\neq y_G\},
\]

\[
R_U(f)=\mathbb E_{G\sim P_U,\,q\sim P(q\mid G)}
\mathbf 1\{f(x_G^{can})\neq y_G\}.
\]

它不是同一题的换写法，而是在新的图支持上重新完成推理。稳定性池和迁移池必须在符号生成阶段就分开，不能先写成文本再随机切分。两个池不能共享 world、base query、图哈希、图族或改写 lineage。迁移的核心估计量是规范呈现下的图族差距：

\[
\Delta_T(f)=
\Pr_{G\sim P_{seen}}[f(x_G^{can})=y_G]
-\Pr_{G\sim P_{unseen}}[f(x_G^{can})=y_G].
\]

等价地，\(\Delta_T(f)=R_U(f)-R_S(f)\)。它测量的是图分布支持改变后的风险增量，而不是文本改写带来的翻转。为避免把基础能力低误写成迁移失败，可以再报告归一化迁移保留率

\[
TR(f)=1-\frac{R_U(f)-R_S(f)}{1-R_S(f)},
\]

其中 \(R_S<1\)。主文仍以 \(\Delta_T\) 为主，因为差值更直观，也更容易做置信区间。

有限样本中，在匹配后的已见/未见图对 \((G_i^S,G_i^U)\) 上用

\[
\widehat{\Delta}_T=
\frac{1}{n}\sum_{i=1}^{n}
\left[\mathbf 1\{f(x_{G_i^U}^{can})\neq y_{G_i^U}\}
-\mathbf 1\{f(x_{G_i^S}^{can})\neq y_{G_i^S}\}\right]
\]

估计风险增量，并以图族为 bootstrap 单位。稳定性则在同一 base query 的配对样本上估计

\[
\widehat{SF}=
\frac{\sum_i \mathbf 1\{f(x_i^{can})=y_i,\ f(x_i^{shift})\neq y_i\}}
{\sum_i \mathbf 1\{f(x_i^{can})=y_i\}}.
\]

前一个估计量比较两个图分布，后一个估计量只在同一图的成对呈现上计数；它们的抽样单位和分母都不同。

### 4.3 为什么两者在数学上不是同一个量

稳定性和迁移分别对应两种不同的操作：

| 对象 | 稳定性 | 迁移 |
|---|---|---|
| 固定什么 | 固定潜在任务 \(z=(G,q,y)\) | 固定呈现规则，改变 \(G\) 的分布 |
| 变化什么 | \(r_0\rightarrow r\)，同图换写法 | \(P_S(G)\rightarrow P_U(G)\)，换图族 |
| 数学形式 | 条件概率 / 同一任务内的变体风险 | 两个分布上的期望风险之差 |
| 主要回答 | 会不会因呈现变化而翻转 | 能不能组合到新依赖结构 |

在一般情况下，\(SS\) 与 \(\Delta_T\) 没有恒等关系。两个反例足以说明问题：模型可能对模板敏感而对新图有能力，此时 \(SS\) 低但 \(\Delta_T\) 小；也可能对模板不敏感却只记住已见图组合，此时 \(SS\) 高但 \(\Delta_T\) 大。因此二者是否相关必须在独立模型、checkpoint 或训练条件上估计，不能用同一批题的两个分数循环证明。

两个分布使用相同的基础算子和匹配的长度、标签与模板，主要差异是依赖图或算子组合是否在发现阶段出现过。因此，\(SS\) 衡量“同一图换一种呈现后能否保住答案”，\(\Delta_T\) 衡量“换到新图后能否完成新的依赖组合”。

## 5. 候选错误规律

候选解释是：模型的一部分错误来自“依赖跟踪负担”，而不只是题目长。

- **相关前提距离：** 真正需要联合使用的前提，在文本里相隔多远；
- **活动依赖前沿：** 推理过程中，最多有多少个尚未完成、但不能丢掉的依赖；
- **算子协调数：** 最终答案需要同时协调多少个关系。

候选模型为：

\[
\operatorname{logit}\Pr(e_{m,x}=1)=\alpha_m+\beta_1D_{rel}(x)+\beta_2F_{active}(x)+\gamma^\top Z(x),
\]

其中 \(Z(x)\) 控制总长度、图规模、目标位置、模板、标签、深度和分支数。

### 5.1 把“具体规律”写成可预测对象

为了避免把三个特征的相关性直接叫作规律，主确认模型保留三个特征的向量形式：

\[
\operatorname{logit}\Pr(e_{m,x}=1)
=\alpha_m+\beta_D\widetilde D_{\mathrm{rel}}(x)
+\beta_F\widetilde F_{\mathrm{active}}(x)
+\beta_K\widetilde K_{\mathrm{op}}(x)
+\gamma^\top Z(x).
\]

负担分数只作为预先指定权重下的可视化摘要：

\[
B(x)=w_D\widetilde D_{\mathrm{rel}}(x)
+w_F\widetilde F_{\mathrm{active}}(x)
+w_K\widetilde K_{\mathrm{op}}(x),
\qquad w_D,w_F,w_K\geq 0,
\]

其中波浪号表示在 discovery split 内标准化，\(K_{\mathrm{op}}\) 是证明中需要协调的算子数量。除非权重在 discovery split 中冻结，否则不能在确认集重新拟合 \(B(x)\)。具体规律不是“某个特征和错误相关”，而是下面这个可被样本外推翻的命题：

\[
\Pr(e_{m,x}=1\mid B(x),Z(x))
=\sigma\!\left(\alpha_m+\phi(B(x))+\gamma^\top Z(x)\right),
\]

其中 \(\sigma\) 是 logistic 函数，\(\phi\) 在工作区间内单调不减。主分析先使用线性 \(\phi(B)=\beta B\)，再用预先固定的单调样条做形状检查。规律要求同时满足：

1. \(B\) 的方向在确认集保持不变；
2. 依赖负担模型优于长度/图规模对照模型；
3. 在预先划定的负担区间上，预测错误率随 \(B\) 单调增加；
4. 结果在正确依赖提示优于 placebo 提示的对照中仍然成立。

因此，规律的核心不是某个回归系数显著，而是一个冻结后的风险排序：负担更高的题，在长度、图规模和模板等因素匹配后，应该有更高的错误风险。

### 5.2 规律的证伪条件

以下任一条件成立，都不能把该模型写成确认性规律：

- 确认集上 \(\phi\) 的方向反转；
- 依赖负担模型的 held-out log loss、Brier score 和校准不优于最强对照；
- 负担区间的错误率不单调；
- 只提高总长度就能复现同样预测，而 \(B\) 没有增量解释；
- 局部子问题和完整证明的错误差异不足，或正确依赖提示与 placebo 提示效果相同。

这些条件允许论文报告“规律不存在”或“规律只在特定区间成立”，而不需要事后修改定义。

在二乘二数据上，还可以把两个结构因素直接放进同一个误差模型：

\[
\operatorname{logit}\Pr(e_{m,x}=1)
=\alpha_m+\eta_S I_{\mathrm{shift}}(x)
+\eta_T I_{\mathrm{unseen}}(x)
+\eta_{ST}I_{\mathrm{shift}}(x)I_{\mathrm{unseen}}(x)
+\beta^\top X(x).
\]

\(\eta_S\) 对应呈现变化造成的稳定性损失，\(\eta_T\) 对应未见图造成的迁移损失，\(\eta_{ST}\) 对应二者是否有额外交互。这个模型不是把 \(SS\) 和 \(\Delta_T\) 合成一个分数，而是把它们作为三个可检验的误差效应。

这只是任务层面的可观察规律，不直接等于模型内部机制。以下结果会削弱或推翻它：

- 局部子问题和完整问题的错误率一样高；
- 长度和图规模模型预测得同样好；
- 确认集上的系数方向反转；
- 正确依赖提示和格式匹配的无关提示带来同样收益。

## 6. 实操方案

### E1：测结构稳定性

先用 ProofWriter 风格的符号规则推理。每个基础问题生成：

- canonical 原题；
- 同一依赖图的合法前提重排；
- 同一依赖图的语义等价模板；
- 相关前提距离变化但总 token 尽量匹配的版本。

增加深度、增加分支、改变算子组合不能算稳定性变换，因为这些操作可能已经改变解题复杂度。

对每一对样本运行同一个冻结模型和确定性解码，计算原题准确率、变体准确率、条件翻转率、恢复率和按 base query 配对的 bootstrap 区间。

### E2：测结构迁移

另建迁移池，留出稳定性池中没出现过的图族和算子组合。至少包括：

- 已见基础算子，但未见的组合；
- 已见局部结构，但未见的整体依赖配置；
- 与稳定性池完全不同的 world 和 base query。

最好采用一个 \(2\times2\) 设计：

| | 规范呈现 | 结构变换呈现 |
|---|---|---|
| 已见图 | 基础能力 | 结构稳定性 |
| 未见图 | 结构迁移 | 迁移与呈现变化的交互 |

设 \(A_{g,p}\) 表示图熟悉度 \(g\in\{seen,unseen\}\) 与呈现方式 \(p\in\{canonical,shifted\}\) 的准确率。则：

\[
\Delta_S=A_{seen,canonical}-A_{seen,shifted},
\]

是已见图上的结构稳定性差距；

\[
\Delta_T=A_{seen,canonical}-A_{unseen,canonical},
\]

是规范呈现下的结构迁移差距；

\[
I_{S\times T}=\left(A_{seen,canonical}-A_{seen,shifted}\right)
-\left(A_{unseen,canonical}-A_{unseen,shifted}\right)
\]

是交互项，表示新图是否会额外放大呈现变化造成的损失。三个式子使用不同的比较方向和不同的数据支持，因此不会把稳定性和迁移写成同一个量。

稳定性和迁移的关系，只能跨多个模型、checkpoint 或训练条件估计，并控制独立测得的 clean competence。不能用同一批题算两个分数再做相关。

### E2.5：正交干预的双重分离实验

二乘二测量说明两个量的定义不同，但还需要一个行为实验检验它们是否真的可以被分别改变。使用相同的基座模型、训练 token、步数、LoRA rank、目标模块和随机种子预算，比较四种条件：

1. **Base：** 不做结构增强；
2. **Render-Aug：** 只加入已见图的等价呈现变体，图分布不扩展；
3. **Graph-Aug：** 只加入 canonical 呈现下的结构组合增强，保持呈现规则固定；
4. **Joint：** 同时加入两种增强。

每个条件都在四个保护评估格上测试：已见图/canonical、已见图/shifted、未见图/canonical、未见图/shifted。主要预测是：

- Render-Aug 应显著提高 \(SS\) 或降低 \(SF\)，但对 \(\Delta_T\) 的改善应不超过预注册的等价界限；
- Graph-Aug 应显著降低 \(\Delta_T\)，但对 \(SS\) 的改善不应自动出现；
- Joint 才预期同时改善两个指标。

令相对 Base 的稳定性收益和迁移收益为

\[
G_S(c)=SS_c-SS_{\mathrm{Base}},\qquad
G_T(c)=\Delta_{T,\mathrm{Base}}-\Delta_{T,c}.
\]

用 bootstrap 置信区间和预先设定的等价界限 \(\delta_S,\delta_T\) 做双重分离判定。例如，Render-Aug 只有在 \(G_S>\delta_S\) 且 \(|G_T|<\delta_T\) 时，才算“主要改善稳定性”；Graph-Aug 反之。单纯的显著/不显著不足以证明没有交叉影响。

这个实验的价值是产生双重分离证据：如果只改变呈现的训练也同样大幅改善未见图迁移，或者只改变图组合的训练也同样大幅改善同图稳定性，就说明两者在当前任务上的行为界线还不够清楚，需要收紧数据构造或承认二者高度耦合。

### E3：发现并确认规律

先只在 discovery split 上选择特征、交互项和随机效应，然后冻结：

- 相关前提距离的算法；
- 活动依赖前沿的算法；
- 主要回归公式；
- 预期系数方向；
- 长度模型、图规模模型和深度/分支模型等对照。

在 confirmatory split 上比较 held-out log loss、Brier score、校准、排序相关，以及不同负担区间的错误率。再加入局部子问题、正确依赖提示和 placebo 提示实验。

### E4：检验边界

把冻结的特征、标准化参数、模型规格和系数方向搬到第二个推理任务族，换模板、词汇和渲染规则。方向和预测能力都保持，才有跨任务支持；只在第一任务成立，就写成任务边界。

把一个测试条件写成 \(\tau=(\mathcal G,\mathcal R,\mathcal Q,m,d)\)，分别表示图分布、呈现分布、任务族、模型和解码条件。定义规律在条件 \(\tau\) 下有效，当且仅当：

\[
V(\tau)=
\bigl(
V_{\mathrm{direction}}(\tau),
V_{\mathrm{prediction}}(\tau),
V_{\mathrm{calibration}}(\tau)
\bigr).
\]

只有三项都为 \(1\) 时，才把条件 \(\tau\) 纳入完整适用域。分别报告三项，可以区分“方向仍对但预测优势消失”和“预测优势仍在但校准失效”。

具体判定为：

- **方向一致：** 主要系数和发现阶段预期方向一致；
- **预测优于对照：** held-out log loss 或 Brier score 相对最强 nuisance-only 对照改善超过预注册幅度；
- **校准通过：** 校准斜率、可靠性图和负担分箱误差在预注册范围内。

这样，适用边界不是一句“换个任务试试”，而是记录在哪些 \(\tau\) 上 \(V(\tau)=1\)。边界实验依次改变任务族、图族组合、呈现规则、模型规模和训练干预，每次只改变一个主要因素。

最后才考虑 LoRA：冻结基座、clean-only LoRA、随机合法结构增强 LoRA、可选的错误引导结构 LoRA。匹配 rank、目标模块、训练 token、步数、标签比例、随机种子和计算量。只在已见变体上提升叫局部适应；未见图族也提升，才说明迁移层面发生变化。

## 7. 论文证据顺序

1. 原题答对后，等价呈现变化是否仍造成条件翻转；
2. 稳定性是否能预测独立迁移，或明确报告没有关系；
3. 冻结后的依赖负担规律能否预测未见结构错误；
4. 第二任务族和训练干预支持或限制了什么。
