# 论文蓝图：从结构稳定性到结构迁移

## 论文主线

论文不再围绕“结构鲁棒性是否影响泛化”这一句宽泛问题展开，而是按四步推进：

1. 模型能不能保持已经展示出来的推理能力；
2. 这种稳定性是否能迁移到没见过的新依赖结构；
3. 什么样的依赖负担能预测错误；
4. 这个规律在哪些任务、模型和训练条件下失效。

## 数学对象

### 结构稳定性

把潜在推理任务写成 \(z=(G,q,y)\)，文本只是呈现函数 \(x=R(z,r)\)。同一依赖图 \(G\) 的规范呈现和变体呈现分别记为 \(x\) 与 \(T_sx\)。要求：

\[
G(T_sx)=G(x), \quad q(T_sx)=q(x), \quad y(T_sx)=y(x).
\]

稳定性固定 \(z\)，只改变呈现 \(r\)。因此它是同一任务内的条件不变性，主指标是：

\[
SS(f)=P(f(T_sx)=y\mid f(x)=y),
\]

或等价地，把条件翻转率写成 \(R_{stab}(f)=1-SS(f)\)。这个量回答“原题已经答对时，换一种等价写法会不会翻转”。

作为偏置检查，补充报告同一潜在任务的两个随机等价呈现的一致率：

\[
INV(f)=E_{z,r,r'}[\mathbf 1\{f(R(z,r))=f(R(z,r'))\}].
\]

它和 \(SS\) 不同：模型可以稳定地犯同一种错，因此 \(INV\) 高而 \(SS\) 低。

### 结构迁移

迁移池包含发现阶段没有出现过的图族或算子组合，记为 \(\mathcal D_U\)。这里不再固定单个 \(z\)，而是比较已见图分布 \(P_S(G)\) 和未见图分布 \(P_U(G)\) 上的风险：

\[
R_S(f)=E_{G\sim P_S}[\mathbf 1\{f(x_G^{can})\neq y_G\}],\qquad
R_U(f)=E_{G\sim P_U}[\mathbf 1\{f(x_G^{can})\neq y_G\}].
\]

规范呈现下的迁移差距为：

\[
\Delta_T(f)=
P_{G\sim P_S}[f(x_G^{can})=y_G]
-P_{G\sim P_U}[f(x_G^{can})=y_G].
\]

即 \(\Delta_T=R_U-R_S\)，回答“换到新的依赖图以后，错误风险增加多少”。两者的数学操作不同：稳定性是固定 \(z\) 后对呈现随机变量取条件概率；迁移是固定规范呈现后对两个 \(G\) 分布取期望之差。因而 \(SS\) 高并不推出 \(\Delta_T\) 小，反之亦然。

实际估计时，迁移差距以图族为 bootstrap 单位；稳定性以同一 base query 的样本对为配对单位。两者连抽样单位都不同，不能合并成一个分数。

### 二乘二分解

令 \(A_{g,p}\) 是图熟悉度 \(g\) 和呈现方式 \(p\) 下的准确率：

\[
\Delta_S=A_{seen,canonical}-A_{seen,shifted},
\]
\[
\Delta_T=A_{seen,canonical}-A_{unseen,canonical},
\]
\[
I_{S\times T}
=(A_{seen,canonical}-A_{seen,shifted})
-(A_{unseen,canonical}-A_{unseen,shifted}).
\]

分别对应稳定性差距、迁移差距和交互效应。这里的三个比较不是同一个指标的换名。

### 正交分离实验

为了把“定义上不同”推进到“行为上可分离”，设置四种匹配训练条件：

1. Base：不做结构增强；
2. Render-Aug：只扩充同图的合法呈现；
3. Graph-Aug：只扩充 canonical 呈现下的新图组合；
4. Joint：同时扩充两者。

对条件 \(c\) 定义相对于基座的两个收益：

\[
G_S(c)=SS_c-SS_{\mathrm{Base}},\qquad
G_T(c)=\Delta_{T,\mathrm{Base}}-\Delta_{T,c}.
\]

Render-Aug 只有在 \(G_S\) 超过稳定性界限且 \(G_T\) 落入迁移等价界限内时，才支持“主要改变稳定性”；Graph-Aug 的判定反过来。这里必须用等价检验或置信区间，而不能用“一个显著、另一个不显著”代替。

## 具体规律：依赖负担风险定律

不把“距离、前沿、算子数与错误相关”直接称为规律。先定义标准化依赖负担：

\[
B(x)=w_D\widetilde D_{\mathrm{rel}}(x)
+w_F\widetilde F_{\mathrm{active}}(x)
+w_K\widetilde K_{\mathrm{op}}(x),
\qquad w_D,w_F,w_K\geq 0.
\]

规律写成条件错误风险：

\[
\Pr(e_{m,x}=1\mid B(x),Z(x))
=\sigma\left(\alpha_m+\phi(B(x))+\gamma^\top Z(x)\right),
\]

其中 \(Z(x)\) 控制长度、图规模、深度、分支、目标位置和模板，\(\phi\) 在工作区间内单调不减。主模型使用线性 \(\phi\)，单调样条只用于检查形状。

这条规律的可证伪版本是：在控制 \(Z\) 后，\(B\) 更高的题应有更高错误风险；依赖负担模型应优于最强 nuisance-only 对照；负担分箱错误率应单调增加。方向反转、预测优势消失、分箱不单调或 placebo 提示同样有效，都不能写成确认性规律。

## 适用边界理论

把测试条件写成

\[
\tau=(\mathcal G,\mathcal R,\mathcal Q,m,d),
\]

分别表示图分布、呈现分布、任务族、模型和解码条件。冻结 discovery 得到的特征算法、标准化参数、模型规格和系数方向后，定义：

\[
V(\tau)=
\mathbf 1\{\text{方向一致}\}
\mathbf 1\{\text{预测优于最强对照}\}
\mathbf 1\{\text{校准通过}\}.
\]

规律的适用域是

\[
\mathcal A=\{\tau:V(\tau)=1\},
\]

而不是“在第二任务上也跑一次”。边界实验一次改变一个主要因素，记录 \(\tau\) 和 \(V(\tau)\)，从而区分任务族边界、图分布边界、呈现边界、模型边界和干预边界。

## 核心假设

- H1：同图变换会产生条件翻转，且该效应不能完全由长度、位置和模板解释；
- H2：稳定性和迁移有关，但在独立数据池上不是同一个量；
- H3：相关前提距离、活动依赖前沿和算子协调数能解释额外错误；
- H4：冻结后的规律能在确认集上优于长度模型和图规模模型；
- H5：规律在第二任务族上的复现程度定义其适用边界；
- H6：训练只有在未见图族上也提高时，才支持可迁移的结构改进。
- H7：只增强等价呈现的训练主要改善 \(SS\)，只增强图组合的训练主要改善 \(\Delta_T\)；若该双重分离失败，说明两个行为量在当前任务上高度耦合。
- H8：冻结后的依赖负担规律在适用域 \(\mathcal A\) 内保持方向、预测优势和校准，在域外至少有一项失效。

## 结果解释规则

- clean 低：不能谈结构能力；
- clean 高、稳定性低：呈现脆弱；
- clean 高、稳定性高、迁移低：熟悉结构执行稳定，但不会组合新结构；
- 稳定性和迁移都高：支持系统性结构推理；
- 规律只在发现集有效：探索性结果；
- 规律在确认集失败：不能写成机制解释；
- LoRA 只提升已见变体：局部适应；
- LoRA 同时提升未见图族：支持迁移层面的干预证据，但不自动等于内部因果机制。
