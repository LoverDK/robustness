# 论文骨架：同图稳定性与未见依赖结构

骨架对应收缩后的 C1 与 C2。测量工具是求解器验证的潜在任务，不是一篇以基准本身为贡献的 benchmark 论文。E0 尚未作为门禁结果写入任何贡献句，因此第 3 条贡献只写实验将要报告的估计量，不写效应方向。

### 1. Paper-type positioning

- Type: New Problem/Setting Paper
- Rationale: 社区已经在研究前提顺序和依赖图难度；这篇论文要成立的是一个尚未被估计过的分割，即同图呈现翻转和换图族失败是不是同一件事，负担抽样只是用来探测这个分割的干预。

方法不必战胜均匀随机，论文仍然回答它提出的问题。因此叙述重心是目标，不是一个保证涨点的技术。

### Methodology outline

Section 3 的开头用模板中的那句主题句。小节如下。

**3.1 潜在任务与呈现。** 潜在任务是依赖图、查询和求解器标签；呈现只改变句子顺序以及是否加入不改变标签的干扰前提。展开时写清：四种图族、规范顺序的定义（与证明顺序一致）、偏移呈现（逆序、随机、带干扰的随机）、以及 yes/no 标签为何必须 1:1。

**3.2 两个估计量。** 条件翻转率只在规范呈现答对的任务上计数；换图差距只比较两个图族的规范呈现。展开时写清二者的抽样单位不同，以及交互项是“偏移呈现下的换图差距”减去“规范呈现下的换图差距”。不要把旧框架里的 V(τ) 和八个假设写回来。

**3.3 池的隔离。** 稳定池用 seen 图族，迁移池用 unseen 图族，二者不共享图族、任务标识和符号实例；训练词表与评估词表分开，避免评估词泄漏。展开时说明这个隔离发生在生成阶段，而不是先写成文本再随机切分。

**4.1 负担特征。** 三个特征只看相关规则的文本位置。展开时给对齐链和逆序链各一个可手算的例子，用来固定 F_active 是“读完并尝试触发之后仍未闭合的规则数”。

**4.2 抽样规则。** 候选呈现来自同一潜在任务；分数高且当前模型在规范呈现答对、在该呈现答错的样本优先。展开时写明与均匀随机共用预算的方式：同样数量的训练 token，而不是同样数量的潜在任务再乘上不同的呈现数。

**4.3 对照条件。** B0 到 B3 与负担抽样的唯一设计差别是“哪些呈现进入训练集，以及是否加一致性项”。rank、目标模块、步数和优化器保持一致。展开时说明一致性项借用的是“变体拟合规范输出”这一形式，不是把 BCT 的偏见句原样搬来。
