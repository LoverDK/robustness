# 结构鲁棒性

这份仓库是研究项目的一份文件快照：论文、实验代码、实验结果，以及记录判断和进度的文档。

- `paper/`：中文稿和英文稿的 tex 与 pdf。编译用的三张图也放在各自目录里，原件在 `figures/`。
- `src/`、`tests/`、`configs/`、`scripts/`：数据生成、训练评估和对照分析的代码。
- `experiments/`：指标、重算和机制对照。阶段结论在 `experiments/e1/stage_c1.md`。
- `build/e0`、`build/e1`：健全性检查和试点的生成文本、指标。不含 LoRA 权重。
- `docs/`：文献、问题拆分、命题和交接记录。
- `proof/`：正文定理对应的 Lean 证明。
- `research/`、`manuscript/`：较早的框架笔记和稿件草稿。
- `midterm/`：中期答辩幻灯片、讲稿、评委问答，以及中期检查表的原件和已填稿。学院幻灯片模板也在这里。

没有放进来的有：模型缓存、虚拟环境、八份约 70MB 的 adapter 权重，以及做表时的检查截图。交接记录里的学号已从那份文档的公开副本中删去；中期检查表本身按原件放入。
